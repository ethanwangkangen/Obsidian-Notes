4 places that code is stored
- Local working directory
- Staging area
- Local repo
- Remote repo

Git pull is 2 commands in one
- Git fetch
	- Remote -> Local
- Git merge
	- Local -> working dir

Git merge vs rebase vs squash commit
- Merge preserves history and adds mergs ccommit
- Rebase replays commits on top -> linear history

Branch
- A branch points to the 'tip' of the branch

Head
- Head points to a commit
- Usually points to Branch, but can detach and point to any commit
