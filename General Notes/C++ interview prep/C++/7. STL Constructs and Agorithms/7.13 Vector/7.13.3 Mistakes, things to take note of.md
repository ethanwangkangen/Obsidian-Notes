# Initialising
- Common bug
	- `vector<Obj> v{3, Obj{1}};`
		- This doesn't work! 
		- Remember that brace initialisation prefers initialiser list overload
		- Instead, correct syntax is `vector<Obj> v(3, Obj{1});`

- Think about how initialising works
	- Relevance: **move only types**
	- What happens with `vector<Obj> v(3, Obj{1});`
		- Each element of vector is the **copy constructed** with the Obj as the second argument
		- Can't do this with move only types, like std::thread
	- Solution
		- Just `emplace_back()`
